# File Cleaner & Organizer

A fast command-line utility built in Python to organize cluttered directories by sorting files into categorized subfolders based on extension.

## Features
- Automatically categorizes files into Images, Documents, Videos, Code, and Archives.
- Formatted summary output powered by Rich.
- Tested with `pytest` and linted with `ruff`.
